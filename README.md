# DevPulse

DevPulse is a developer event discovery platform that helps users explore upcoming workshops, hackathons, and tech meetups.

## Features

- Browse upcoming events
- Search events by title, description, and category
- View detailed event information
- RSVP for events
- Responsive user interface

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS

## Future Improvements

- User authentication
- Admin dashboard
- Database integration
- Event creation system
